Owner check: the code sandbox (isolation)

Tries to break out of Noria's code sandbox, in this browser, on this site. It runs deliberately hostile code inside the sandbox: reaching the internet (fetch, XMLHttpRequest, WebSocket, dynamic import), reading this page's storage and your Noria session, touching the page, endless loops, floods of output, malformed results, and leaving state behind for the next run. Every attempt must fail, and the page must stay responsive.

It sends nothing anywhere and reads nothing of yours: the only "secret" is a random canary value it plants itself. Session tokens are never shown. What it cannot test: memory exhaustion (a browser gives a page no way to cap memory; the timeout is the only bound), so no memory bomb is run.
