Africa, live and verified — all 54 countries

The current temperature and local time for the capital of every African country, fetched live from Noria’s own reality API and refreshed continuously. Each temperature is cross-checked across two independent authoritative sources before it is shown — the same verification Noria runs before she states any live figure. Nothing here is written by the model, so there is nothing to hallucinate.

How this stays honest

Every card is refreshed by calling Noria’s live endpoint POST /brain/tool with weather.get. That runs the reality layer: it asks Open-Meteo and MET Norway at the same moment and returns a temperature only when the two agree — marked VERIFIED, with the source names and the exact time the reading was taken shown on the card. Cities refresh in a rotating cycle (to respect the API’s rate limit), so each card carries its own “updated … ago”. Local clocks tick every second from each city’s time zone. If the two sources ever disagree or a source is down, the card says so rather than showing a number — Noria never fills a gap with a guess.
