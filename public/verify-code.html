Owner check: real tasks with code execution

Runs real objectives that need computation, in production, with your own signed-in session and the real code sandbox in this browser: analyse a sales file (with a malformed row) and produce a table, a report and a chart; make failing tests pass; catch a wrong loan calculation with an independent cross-check; and keep hostile output from steering anything. Each objective is a task graph: plan, run code in the sandbox, verify, create artifacts, feed results back, recover from failures. Everything is stored in one clearly named test project in your account, and nothing leaves your account or the sandbox.

The code is written by the check itself (not by a model): this proves the machinery around the code. How well a model writes such code is measured separately.
